# 2026-NJU-DSA
## This is a repository for learning in NJU-DSA
All DataStructures are in `DataStructure.h`, it is a STB file.
If you wany to use one datastructure, following is an example:
```cpp
#define DS_SINGLYLINKEDLIST_IMPLEMENTATION // To use SinglyLinkedList
#include "DataStructure.h"
// Code
// You can use SinglyLinkedList now
```

## The DataStuuctures supported now (2026-09-08):

1. SeqList
2. SinglyLinkedList
3. CircularLinkedList
4. DoublyLinkedList
